# 🦷 Projeto de Estudo: Landing Page Odontológica

Este repositório faz parte do meu cronograma de estudos focado em **Frontend Development** e **UX/UI Design**. O objetivo foi aplicar conceitos modernos de desenvolvimento para criar uma landing page institucional funcional e de alta conversão.

## 🎯 Objetivos de Aprendizagem
- **Tailwind CSS:** Implementação de layouts complexos e responsivos sem sair do HTML.
- **Mobile-First:** Garantir que a experiência de agendamento seja perfeita em dispositivos móveis.
- **SEO & Performance:** Estruturação semântica de tags para melhorar o ranqueamento orgânico.
- **Integração de APIs:** Uso de Google Maps Iframe e integração de links dinâmicos para WhatsApp.

## 🏗️ O Projeto
Utilizei o nicho de odontologia para praticar a criação de interfaces que exigem alta percepção de valor, limpeza visual (utilizando uma paleta Rosa Bebê) e autoridade técnica.

## 🛠️ Tecnologias
- HTML5 / CSS3
- Tailwind CSS (via CDN para prototipação rápida)
- JavaScript Vanilla
- Git & GitHub Pages (Deploy)
